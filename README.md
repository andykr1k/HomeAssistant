# HomeAssistant

## Download Voices:

```bash
git clone https://huggingface.co/rhasspy/piper-voices
```

## Run

```bash
python src/main.py
```

## Optional configuration

Set these environment variables to enable integrations:

- HOME_ASSISTANT_URL, HOME_ASSISTANT_TOKEN
- LIGHT_ENTITY_IDS (comma-separated)
- TV_ENTITY_ID
- THERMOSTAT_ENTITY_ID
- WEATHER_LAT, WEATHER_LON, WEATHER_LOCATION, WEATHER_UNITS
- STT_MODEL_SIZE, STT_DEVICE, STT_COMPUTE_TYPE
- STT_WINDOW_SECONDS, STT_BEAM_SIZE, STT_VAD_FILTER, STT_RMS_THRESHOLD, STT_RMS_END_THRESHOLD, STT_SILENCE_SECONDS
- TTS_MODEL
- CALENDAR_ICS_URL, CALENDAR_ICS_SOURCES, CALENDAR_TIMEZONE, CALENDAR_MAX_ITEMS
- LLM_MODEL_ID, LLM_DEVICE, LLM_DTYPE, LLM_TRUST_REMOTE_CODE, LLM_TEMPERATURE, LLM_MAX_TOKENS, LLM_TOOL_TEMPERATURE, LLM_TOOL_MAX_TOKENS
- BROWSER_SHOW_OVERLAY
- CAMERA_URL, CAMERA_STATUS_URL, CAMERA_STATUS_POLL_SECONDS
- CODE_ROOT, CODE_PROJECTS_ROOT, CODE_DEFAULT_PATH, CODE_MAX_CHARS
- MEMORY_ENABLED, MEMORY_DB_PATH, MEMORY_EMBED_MODEL, MEMORY_EMBED_DEVICE
- MEMORY_TOP_K, MEMORY_MAX_CHARS, MEMORY_TOOL_MAX_CHARS
- MEMORY_RECENCY_DAYS, MEMORY_CANDIDATE_LIMIT
- MEMORY_SUMMARY_ENABLED, MEMORY_SUMMARY_EVERY, MEMORY_SUMMARY_TURN_LIMIT, MEMORY_SUMMARY_TURN_CHARS, MEMORY_SUMMARY_MAX_CHARS
